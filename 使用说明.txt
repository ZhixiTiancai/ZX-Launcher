智熄的启动器 0.3.6 / Windows 10、11 64 位

启动方法
1. 将整个压缩包解压到一个可以写入文件的文件夹。不要在压缩软件内直接运行。
2. 双击“智熄的启动器.exe”。请保留旁边的 App.xaml、engine、runtime、data 等文件夹。
3. 发行包预装“愚者 0.3.1”的配置及已成功补全的模组。点击“校验 / 补全文件”可检查。
4. 点击右上角“账号”，选择已保存的微软账号后点击“使用此账号”。
   新增微软账号：在账号窗口的“登录配置”填写自己的应用 Client ID，再点击“登录 / 添加微软账号”。
   按提示在微软官方网页输入设备代码并完成授权，启动器自动验证资格并保存账号。
   如尚无应用编号，可暂时继续使用已保存账号；也可在“高级设置”中使用原版 Prism 的账号登录。
   需要有 Minecraft Java 版有效游戏资格。不要把账号文件发给他人。
5. 选择整合包，点击“启动游戏”。
   0.1.1 会先补全并校验 Minecraft、Forge、LWJGL 等组件元数据，避免由 Prism 重下大型版本索引。
   0.1.2 还会预下载和校验游戏本体、库文件、Forge 安装器依赖与声音/贴图资源。
   游戏文件优先官方地址，失败时尝试 BMCLAPI 镜像；账号授权仍直接使用微软官方服务。
   首次启动，Prism 会联网下载 Minecraft 游戏本体、资源、Forge 和相关依赖。
   如点击启动后出现账号选择窗口，选择你的正版账号继续。

第一版的实现范围
这是独立编写的中文界面、整合包导入器与校验下载器。
原生账号管理和已配置应用的微软登录在本界面中完成。
游戏依赖安装和游戏进程启动通过捆绑的未修改 Prism Launcher 11.1.1 完成。
本项目与 Prism Launcher、Mojang、Microsoft 均无隶属或背书关系。
界面支持 Modrinth .mrpack，以及内部含 modrinth.index.json 的 .zip。
0.1.9 新增 CurseForge manifest.json 整合包导入，可直接使用左侧“导入整合包”。
Forge / NeoForge / Fabric / Quilt 的实例元数据可生成；此版重点测试愚者 0.3.1（1.20.1 / Forge 47.4.12）。
按官方组件元数据选择随附的 Java 17 / 21；例如 1.20.1 使用 17，1.21.1 使用 21。
已有的 Prism 账号可直接选择；原生新增微软账号需要配置自己的 Microsoft 应用 Client ID。

常见操作
· 整合包不能导入：检查 ZIP 内是否存在 Modrinth 的 modrinth.index.json 或 CurseForge 的 manifest.json；不按扩展名猜格式。
· 下载中断：重新点击“校验 / 补全文件”，已经通过大小及 SHA 校验的文件会跳过。
· 停止任务：点击“停止任务”，已下载完成文件会保留；未完成文件重新下载。
· 某个 Mod 下载失败：点击“查看缺失清单”，用浏览器下载清单中的文件，再点“补入已下载文件”。
  程序只接收名称和 SHA 校验均匹配的文件，不会把错误页面当作 Mod。
· 修改包之前请关闭随附 Prism 及游戏；避免两个程序同时写同一实例。
· 推荐先分配 8 GB 内存。若电脑总内存只有 8 GB，可尝试 4 GB，但大型整合包可能无法运行。
· 游戏闪退：Prism 会显示启动日志；也可以打开“游戏目录”查看 logs/latest.log 或 crash-reports。
· 想移动整个启动器：先退出 Prism 与游戏，再搬动完整文件夹，回到此界面启动会更新 Java 路径。
· 备份存档：退出游戏后点击“导出存档”，将当前整合包的全部世界保存为 ZIP。不要删除 data 文件夹。

文件位置（相对于 EXE）
engine/                         未修改的 Prism Launcher 正式版
runtime/                        Eclipse Temurin Java 17 / 21 JRE（含其许可）
data/instances/<实例编号>/minecraft/  每个包的模组、配置、存档
data/accounts.json              Prism 保存的账号数据，包含敏感授权信息，请勿发送给他人
logs/launcher.log               本界面的任务日志，不记录账号授权令牌
source/                         本界面的源码和构建脚本
third-party/source/             Prism 对应发行源码

0.1.6 导出整合包
选中整合包，点击“游戏目录”右侧的“导出整合包”，选择 ZIP 保存位置。
默认保存到启动器目录下的 exports 文件夹，完成后会在资源管理器中选中导出文件。
ZIP 包含当前模组、配置、资源包、光影、自定义名称与图标，并带有包内文件校验清单。
按当前文件状态导出，所以新增或修改的模组会保留，已删除的模组不会重新添加。
默认跳过存档、截图、日志、地图历史、缓存和常见登录凭据文件；不包含启动器账号。
朋友在启动器里点击“导入整合包”，直接选择这个 ZIP，不需要手动解压。
首次启动仍需联网补齐 Minecraft 本体、运行时和加载器依赖，并登录自己的正版账号。
导出前请退出 Prism 与游戏，避免文件在导出时被修改。导出中可停止，原有 ZIP 会保留。
0.1.7 Mod目录与存档导出
“游戏目录”右侧新增“Mod目录”，点击直接打开当前整合包的 mods 文件夹。
“导出整合包”右侧新增“导出存档”，将当前整合包 saves 下的全部世界单独导出为 ZIP。
包含世界、所有维度、玩家数据、进度和数据包；保留 level.dat_old，不包含 session.lock。
默认保存到启动器的 exports，文件名包含整合包名称和导出时间，完成后在资源管理器中选中。
导出前请保存世界并退出游戏与 Prism；没有世界、存档被占用或包含目录链接时会明确提示。
可点击“停止任务”取消，原有 ZIP 不受影响。
恢复方法：先安装相同版本的整合包，退出游戏；解压 ZIP，把其中 saves 下需要的世界文件夹
复制到目标整合包“游戏目录”的 saves 中。已有同名世界时，先备份或给导出的文件夹改名。
存档 ZIP 不是整合包，不使用“导入整合包”功能；ZIP 内附有“存档恢复说明.txt”。

0.1.8 账号管理
版本号移到启动器标题后，原右上角位置改为“账号”按钮，显示当前角色和离线状态。
· 使用此账号：选择已有记录，后续启动将明确指定该账号。
· 离线使用：保留所选角色并切换到离线启动；不具备正版服务器认证能力。
· 添加离线角色：输入 3–16 位英文字母、数字或下划线，生成独立的离线 UUID。
  更换角色可能影响世界中的玩家身份。遵循原版 Prism 规则，离线使用需要保留至少一个已验证的 Java 版微软账号。
· 退出当前账号：清除当前选择，保留登录记录。移除账号只删除本机记录，不删除微软账号或存档。
· 登录 / 添加微软账号：配置应用编号后，显示登录代码并提供微软官方网页入口。
  密码和验证码只填写到微软官方网页；取消、超时或失败不会替换原账号。
· 刷新登录：更新通过已配置应用登录的账号；原 Prism 应用保存的账号由原引擎在启动时验证。
· 修改账号、登录或刷新前请退出 Prism 与游戏。

应用编号位置：Microsoft Entra 管理中心 https://entra.microsoft.com/ → 应用注册 → 你自己的应用 → 概述 → 应用程序（客户端）ID。
未注册应用就没有此编号；它不是微软账号 ID 或 Minecraft UUID。不需要 Client Secret。
应用需支持个人微软账号、启用公共客户端流程，且被 Minecraft 服务允许进行登录；仅创建编号不保证有接口资格。
官方注册说明：https://learn.microsoft.com/en-us/entra/identity-platform/quickstart-register-app

账号文件：data/accounts.json 与 Prism 共享，包含敏感凭据，不要分享。账号选择与公开应用编号保存在 data/zhixi-account-settings.json。
修改账号记录前会在 data/account-backups 中创建 Windows 当前用户绑定的 DPAPI 加密备份；不要将它们放进朋友分享包。
本版已用模拟响应验证完整授权链路和账号存储，真实新增微软登录仍需配置可用的应用编号并由用户完成网页授权。

0.1.9 CurseForge 整合包
导入入口支持根目录包含 manifest.json、manifestType 为 minecraftModpack 的 CurseForge ZIP。
按清单中的游戏与主加载器版本安装，不替换为其他版本。默认导入 required 文件，跳过明确标记为可选的条目。
文件信息通过 CurseTools 公共代理 https://api.curse.tools/ 查询，不包含账号或登录凭据。
模组、资源包、光影分别放入 mods / resourcepacks / shaderpacks；下载按返回的大小和 SHA-1 校验。
如果某文件没有自动下载地址，会保留为缺失项。打开“查看缺失清单”，通过 CurseForge 网页下载，
再用“补入已下载文件”导入，哈希正确才会接收；不会把不完整的包标记为就绪。
文件元数据缓存在 data/metadata/curseforge 中，网络查询失败时可稍后重新导入。
普通启动器分享 ZIP 不能通过导入入口添加，应完整解压后运行 EXE。

0.1.10 拖拽导入整合包
从资源管理器把下载好的 ZIP 或 .mrpack 拖到左侧“整合包库”区域，看到“松开以导入”后放开鼠标。
整个左侧列表（包括已有整合包条目）均可接收。原来的“导入整合包”按钮仍可正常使用。
一次最多拖入 20 个文件，按顺序导入和校验；原压缩包保留，不会被移动或删除。
仅支持 Modrinth / CurseForge 整合包格式；请拖文件本身，不要拖文件夹、存档包或启动器安装包。
正在处理任务、随附 Prism 或游戏正在运行时，先完成任务并退出游戏，再导入。

0.1.11 页面导航、删除与个性化
左侧竖栏从上到下：书架＝整合包库，衣服＝皮肤库，齿轮＝设置。
皮肤库目前提供页面入口；皮肤预览、收藏和更换功能将在后续版本加入。

删除整合包：选择整合包，点击“导出存档”右侧的红色垃圾桶。
确认框会显示包名，默认选择“否”。确认后，该包的模组、配置和全部存档一起移入 Windows 回收站。
请先保存世界并退出游戏与 Prism。被占用的存档或含目录链接的实例会阻止删除。
误删恢复：退出启动器，从 Windows 回收站还原该整合包文件夹，再重新打开启动器。
其他整合包、账号及原始导入 ZIP 均不随该实例删除。

设置：语言可选择简体中文或 English，主界面、设置、账号窗口和常用交互立即切换。
整合包/角色自定义名称与游戏内容保持原名；已有日志和部分引擎下载诊断保留原文。
主题提供墨绿、雾蓝、灰玫红、麦黄、烟紫、黑、白七种颜色，白色使用深色文字。
背景支持本地 PNG/JPG/BMP/GIF（32 MB 以内），解码后复制保存在 data/appearance 中。
原图移动后仍可使用；可调节背景遮罩深度，或点击“恢复默认背景”。
语言、主题和背景设置自动保存在 data/zhixi-ui-settings.json，重启后保留。

0.1.12 皮肤库：本地收藏与在线浏览
点击左侧衣服图标进入皮肤库，右上角选择“本地收藏”或“在线浏览 · NameMC”。
本地收藏：批量导入 Minecraft 皮肤 PNG，显示正面和背面，点击“预览”查看大图。
支持 Java 版标准 64×64 和旧式 64×32 皮肤，每张不超过 1 MB；重复文件自动跳过。
“导出 PNG”保存原始图片；“打开收藏目录”可查看 data/skins 下的皮肤及来源记录。

在线浏览：直接在启动器内访问 https://namemc.com/minecraft-skins，可滚动网页、搜索并进入皮肤详情。
打开皮肤详情后，点击启动器“收藏当前皮肤”，或点击网站上的 Download 下载图标。
下载完成并通过 PNG/尺寸检查后，自动加入“本地收藏”；无需再从下载文件夹手动导入。
地址栏可粘贴 NameMC 皮肤详情链接，按 Enter 或点“前往”；提供首页、后退和刷新。
内嵌网页空间不够时，可以最大化启动器或滚动网页。网站内容与广告由 NameMC 提供。
网站可能要求手动完成访问验证；也可使用“外部浏览器打开”，再导入下载的 PNG。
在线浏览需要 Microsoft Edge WebView2 Runtime；本地收藏不依赖浏览器运行环境。
WebView2 的两个 Microsoft DLL、WebView2Loader.dll 及旁边的许可文件请一并保留。
本次只提供皮肤收藏、预览和下载，不会自动修改你微软账号正在使用的皮肤。

Mod 页自动匹配库中当前选中整合包的版本与加载器，并显示唯一安装目标及 mods 路径。
选择项目与适配版本后点击下载，必需前置会一起解析。安装期间目标锁定，不会向其他整合包写入模组。
旧版模组替换前会备份到该整合包的 mod-backups 文件夹；失败时回滚。安装清单同步更新，下次启动校验不会重新恢复已替换的旧版。
整合包下载后自动加入整合包库，并补全模组文件；如个别文件受限或网络中断，可在库中继续“校验 / 补全文件”。
CurseForge 通过 CurseTools 公共代理查询，失败时回退 MCI 公共代理。自动下载遵循作者提供的下载地址；未开放自动下载的文件需通过项目网页处理。


0.3.1：Mod 名称中文显示与快捷方式图标
Mod 下载列表及详情的项目名称会自动匹配中文名，简介、版本号、文件名、项目编号和安装目标不变；整合包名称不受影响。
未收录的名称保持原名，悬停名称可查看原始名称；英文界面显示原名。名称对照表按需下载并缓存在 minecraft/data/metadata/mod-names-v1.json，每周检查更新，失败时保留缓存和常用名称。
名称对照来源：龙腾猫跃 / PCL 公开的 MC 百科条目表 https://github.com/Meloong-Git/PCL/blob/main/PCLCS/Resource/WikiEntries.txt 。本启动器是独立产品，与 PCL 无关联；发行包不包含该完整数据表，按需从公开来源获取。
启动器会修复指向自身的桌面快捷方式图标，保留启动目标、参数和工作目录。图标资源位于 minecraft/launcher/icons，旧快捷方式备份位于 minecraft/launcher/shortcut-backups。

0.3.2：中文 Mod 搜索与 Java 管理
Mod 下载支持中文和英文名称搜索。中文名先匹配已收录的项目，再使用当前整合包的 Minecraft 版本与加载器查询；未收录的中文名请改用英文。不会改动简介、文件名或安装目标。
侧栏皮肤下方的 J 按钮进入 Java 管理。默认每次启动按整合包所需版本选择；选择列表中的 Java 并点击“使用所选 Java”可改为手动，勾选自动选择可恢复。
“检测本机 Java”检查环境变量、注册表、常见安装目录；其他位置可用“手动添加 Java”选择 javaw.exe / java.exe，或“扫描指定文件夹”。仅支持使用 Windows x64 Java，检测不会执行扫描到的程序。
选择 Java 8 / 11 / 16 / 17 / 21 / 25，查询官方版本后可下载 Eclipse Temurin JRE。下载经 SHA-256 校验后保存到 minecraft/runtime，不替换已有 Java，不修改系统环境变量。下载不会改变当前自动 / 手动模式。
设置文件：minecraft/data/java-settings.json。启动器内的运行时路径按相对路径保存，便于整体移动；电脑其他位置的 Java 使用原有绝对路径。


0.3.3：整合包 Mod 管理
整合包页面的 Mod管理可查看、搜索当前整合包模组。悬停一行显示百科、文件定位、启用 / 禁用、删除操作；有更新时还显示向上箭头，由用户确认后安装。
进入页面自动检查更新，成功结果缓存六小时，可点击刷新 / 检查更新强制查询。仅检查兼容当前 Minecraft 和加载器的新正式版；不会自动更新。未识别、未收录或网络失败的模组不视为最新版，行提示中显示检查状态。
MC 百科条目已匹配时直接进入介绍页，未匹配时打开百科搜索。更新会解析必需前置，并保留旧版备份。整合包可能有特定版本搭配，是否更新由玩家决定。
禁用使用 .jar.disabled；删除并备份会从当前 mods 移除文件。文件清单同步修改，校验不会复原这些操作。原文件和原清单保存在当前整合包的 mod-backups 中，可在退出游戏后手动恢复。运行游戏时仅查看，修改前需退出 Prism 和游戏。


0.3.4：拖入本地模组与滚动条
在 Mod 管理列表范围内拖入 .jar 文件，验证通过后复制到当前整合包。每批最多 100 个，每个最大 512 MB；混合无效文件时整批不安装。相同文件跳过，同名或同模组不同版本不直接覆盖。复制成功不代表模组依赖、Minecraft 版本和加载器一定兼容，需自行确认。
自动检查更新等任务运行时，请先完成任务或点击停止任务后再拖入。Prism 和游戏运行时禁止添加。滚动条随主题显示，去除传统灰白轨道和箭头，保留滚轮、拖动和点击轨道翻页。


0.3.5：原版 Minecraft 下载
侧栏整合包下载与皮肤库之间的立方体图标打开原版下载页。显示 Mojang 官方清单中收录的全部 Java 版版本，可筛选正式版、快照 / 预发布版、远古 Beta 与 Alpha，也可搜索具体版本号。清单随官方更新，未公开或未被官方清单收录的版本不在此列表。
选择版本并下载安装后会加入左侧游戏库，独立保存存档和配置。正版账号从右上角管理；启动时自动匹配 Java，缺少对应 Java 时可在 J 页面下载。远古版本通常需要 Java 8。下载不会自动启动游戏。
中断后可在游戏库使用校验 / 补全继续下载，不必删除目录重来。原版没有模组加载器，Mod 管理入口禁用。


0.3.6：随原版安装加载器与 Java 引导
在原版下载页选择游戏版本并点击下载安装，会先弹出加载器选择窗口。可保留纯原版，也可选择 Forge、NeoForge、Fabric、Quilt 及其兼容版本。查询失败时可重新查询或取消，不会悄悄安装其他版本。Fabric API、QSL 等模组 API 不属于加载器本身，需要时请在 Mod 下载中单独添加。
不同加载器 / 版本创建独立实例，不把已有整合包替换成其他加载器。重复下载相同组合会继续补全原实例。
Java 不匹配提示使用主题化窗口。点击前往 Java 管理会定位到下载区域，并预选游戏所需的大版本；也可在上方选择已有的兼容 Java。
