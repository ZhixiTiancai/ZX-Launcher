智熄的启动器 0.2.9 — 朋友分享版（不含整合包）
适用系统：Windows 10 / 11，64 位，.NET Framework 4.8

解压后怎样启动？
1. 将整个 ZIP 完整解压到一个可以写入文件的文件夹。
2. 双击解压后第一层的“智熄的启动器.exe”。
不要在压缩软件里面直接运行，也不要只把 EXE 单独拷走。
第一层只有“智熄的启动器.exe”和 minecraft 文件夹，二者请一起保留。
程序组件、游戏数据、源码和说明均已放入 minecraft，不能只拷走 EXE。
已附带 Java 17 / 21 与原版 Prism Launcher 11.1.1，无需安装 Node 或开发工具。

添加自己的整合包
1. 打开启动器，点击左侧“＋ 导入整合包”。
2. 选择 Modrinth .mrpack / ZIP，或内部根目录包含 manifest.json 的 CurseForge 整合包 ZIP。
   也支持其他人通过本启动器“导出整合包”生成的 ZIP，无需手动解压。
3. 等待导入和文件补全，选择整合包，调整内存。
4. 登录自己的微软账号，然后点击“启动游戏”。
首次会联网补全 Minecraft 本体、加载器、库和资源；本 ZIP 不附带这些游戏内容。
已支持 CurseForge manifest.json；通过 CurseTools 公共代理查询文件信息，按 SHA-1 校验下载。
没有自动下载地址的文件会显示在缺失清单中，可通过作者网页下载后手动补入。
不能把任意 ZIP 当作整合包，启动器分享包应解压后运行 EXE。

首次登录账号（当前推荐方法）
这个干净分享包没有任何预存账号，也未配置 Microsoft 应用 Client ID。
点击主界面中间的“高级设置”打开随附 Prism，按需完成首次初始化。
在 Prism 的账号菜单中选择“管理账号”→“添加微软账号”，由你在微软官方网页完成授权。
需要有 Minecraft Java 版有效游戏资格。登录完成后退出 Prism，回到中文启动器。
点击右上角“账号”，选中自己的账号并点击“使用此账号”，之后即可从中文启动器启动。

右上角的“账号”还支持切换账号、离线使用、添加离线角色、退出和移除本地账号记录。
离线模式需保留至少一个已验证拥有 Java 版的微软账号，不能用于正版服务器认证。
如果要直接在中文账号窗口新增微软账号，先展开“登录配置”填写为此应用注册、
且可调用 Minecraft 登录接口的 Microsoft 应用 Client ID，再点击“登录 / 添加微软账号”。
原生新增登录尚未完成真实账号实测；没有应用编号时，请使用上述 Prism 登录方法。
密码和验证码只填写在微软官方网页，不发送给分享启动器的人。

常用功能
· 名称旁的铅笔：修改整合包名称。
· 点击整合包图标：选择本地图片、下载 HTTPS 图片或恢复默认草方块，左侧列表同步显示。
· 游戏目录 / Mod目录：直接打开当前整合包的对应文件夹。
· 导出整合包：打包当前模组、配置、资源包、光影、名称和图标供他人导入，不含存档和启动器账号。
· 导出存档：退出游戏后，将当前包的所有世界另存 ZIP，内附恢复说明；存档 ZIP 不通过“导入整合包”导入。
· 校验 / 补全文件：下载中断后可重试，已通过哈希校验的文件会跳过。
· 查看缺失清单 / 补入已下载文件：手动下载缺失模组后导入校验。

运行与文件位置
按游戏版本选择随附 Java：例如 Minecraft 1.20.1 使用 Java 17，1.21.1 使用 Java 21。
其他游戏版本可能需要其他 Java，可在 Prism 的设置中选择相应运行时。
整合包：minecraft/versions/<整合包名称-短编号>/minecraft。
每个包的 minecraft 里直接是 mods、config、saves、resourcepacks 等游戏文件。
旧版时间编号文件夹会自动改为整合包名称；已自定义的显示名称和图标保留。
导出文件默认保存在 minecraft/exports 中。修改整合包或导出之前请先退出游戏与 Prism。

此分享包不含你的整合包、账号、授权令牌、存档、截图、导出文件或使用日志。
首次打开整合包库为空是正常现象。朋友需要自行导入整合包并登录自己的账号。
以后分享请发送原始 ZIP，避免把使用后生成的 minecraft 文件夹直接发给别人；其中含个人账号和整合包。
minecraft/data/accounts.json 含有敏感授权信息，切勿发给别人。

minecraft/launcher/source 是中文界面与下载器源码；
minecraft/launcher/third-party/source 是随附组件对应源码。
这些文件用于保留许可和提供源码，不需要安装。第三方许可说明见 THIRD-PARTY.txt。

皮肤与外观
左侧衣服按钮进入皮肤库，可导入本地 PNG 或在 NameMC 中浏览和收藏皮肤。
星标使皮肤优先显示，铅笔可重命名，垃圾桶会确认后移入回收站。
齿轮进入设置，可切换中英语言、七种配色和自定义背景。
在线皮肤浏览需要 Microsoft Edge WebView2 Runtime；本地皮肤收藏可独立使用。

以后怎样更新而不丢整合包？
不要删除旧文件夹。你的整合包、模组、世界和账号都保存在旧目录的 data 里面。
首次使用的朋友：解压完整分享 ZIP 后打开“智熄的启动器.exe”。
已有旧版的朋友：下载单独的“保留数据更新.exe”，双击，选择原来的启动器文件夹，点击“更新此目录”。
更新器会等待旧启动器关闭，验证签名，备份旧程序，再替换程序文件；不会删除或覆盖 data、engine、runtime、exports。
更新完成后点击“启动启动器”，原整合包仍在，无需重新导入。旧程序备份在 updates-backup 文件夹。
也可以在启动器“设置 → 启动器更新 → 从本地更新包安装”选择“程序更新.zip”，再点击安装。
“程序更新.zip”不是整合包，不要拖进整合包库。更新 EXE/ZIP 都需要已有的完整启动器目录。

0.2.7 皮肤使用
在皮肤库点击“使用”，将这张 PNG 应用到当前拥有 Java 版的微软账号。成功后只标记一张“使用中”，重启后保留。
选择另一张会自动替换之前的使用标记；失败或登录失效时保留原选择并显示提示。
请先退出 Prism 和游戏，再应用皮肤；下次进入游戏生效。离线模式不能上传官方皮肤。
删除本地皮肤收藏不会重置账号已使用的官方皮肤。

0.2.8 目录说明
智熄的启动器.exe：唯一启动入口，已嵌入 ZX 图标。
minecraft/versions：各整合包，按名称加短编号分文件夹。
minecraft/runtime：随附 Java 17 / 21。
minecraft/data：账号、皮肤、外观设置与共享资源缓存，请勿删除。
minecraft/exports：默认导出的整合包与存档。
minecraft/launcher：界面、引擎、DLL、源码、许可、说明、日志和更新备份。
旧版收到 0.2.8 更新后，首次打开自动移动原目录文件，无需重新导入。
请退出游戏和 Prism 后更新。以后仍使用设置中的自动更新；不要删旧包重装。
